# Project S.H.O.E.S. — ML Prototype

A simplified machine learning prototype demonstrating the core prediction engine behind **Project S.H.O.E.S.**, an AI-powered platform designed to optimize the end-of-life journey of footwear. Given structured product attributes, the system predicts whether a shoe should be **resold**, **repaired**, or **recycled**, and estimates its current resale market value.

Shoes are notoriously difficult to recycle due to multi-material construction. This prototype encodes that reality directly: recycling is the last resort, not the default.

---

## Quickstart

```bash
pip install -r requirements.txt

# Optional: verify data generation and class distribution
python data.py

# Train both models (~10–20 seconds)
python train.py

# Run the inference demo
python predict.py
```

---

## File Overview

| File | Purpose |
|---|---|
| `main.py` | Rule-based recyclability scorer (original prototype). Imported by `data.py` and `predict.py`. |
| `data.py` | Synthetic dataset generator (7,500 rows). Calls `main.recyclability_score()` to compute the `recyclability_score` feature. |
| `train.py` | Trains a `RandomForestClassifier` (path prediction) and `RandomForestRegressor` (resale value). Saves both as Pipeline objects. |
| `predict.py` | Loads saved models and runs inference on 5 demonstration shoes. |
| `model_classifier.pkl` | Trained classification pipeline (generated by `train.py`). |
| `model_regressor.pkl` | Trained regression pipeline (generated by `train.py`). |

## Input Features

| Feature | Type | Description |
|---|---|---|
| `category` | categorical | sneaker, boot, sandal |
| `material` | categorical | leather, synthetic, mixed |
| `brand_tier` | categorical | premium, mid, fast |
| `condition_score` | float [0–1] | Overall shoe condition |
| `age_months` | int | Months since original purchase |
| `original_price` | float | Original retail price (USD) |
| `resale_market_demand` | float [0–1] | Estimated current resale demand |
| `recyclability_score` | float [0–1] | Fraction of materials accepted by local recycling (from `main.py`) |

## Predicted Outputs

| Output | Type | Description |
|---|---|---|
| `optimal_path` | string | resale / repair / recycle |
| `resale_value` | float | Estimated current resale price (USD) |

## Labeling Logic

Labels in the synthetic dataset are assigned by rule (in priority order):

1. **Resale** — `condition_score > 0.60` AND `resale_market_demand > 0.30`
2. **Recycle** — `condition_score < 0.20` AND `age_months > 30` *(truly end-of-life)*
3. **Repair** — everything else *(the majority outcome)*

Expected class distribution: repair (~57%) > resale (~28%) > recycle (~15%)

Resale value formula:

```
resale_value = original_price × condition_score × resale_market_demand × brand_multiplier + noise
```

Brand multipliers: premium = 1.1 · mid = 0.9 · fast = 0.6

## Architecture Notes

- The `ColumnTransformer` preprocessor is embedded inside each `Pipeline` object, so `predict.py` calls `pipeline.predict(df)` directly on raw input DataFrames — no separate preprocessing step.
- `OneHotEncoder(handle_unknown="ignore")` makes inference robust to novel category values.
- `class_weight="balanced"` on the classifier compensates for the repair-dominant class distribution.
- `main.py` is unchanged from the original prototype. Its `recyclability_score()` function is imported (not copied) into `data.py` and `predict.py`, keeping the material-scoring logic in a single place.

## How This Extends

Because data generation, training, and inference are fully separated:

- Swap synthetic data for real labeled records without touching `train.py`
- Replace `RandomForest` with XGBoost or a neural network by changing one class in `train.py`
- Wrap `predict.py` logic in a FastAPI endpoint for mobile integration
- Add SHAP explanations to surface feature importance per prediction
- Feed real scan data (image → material composition) into `build_feature_row()` as the computer vision layer matures
